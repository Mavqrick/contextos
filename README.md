# ContextOS — AI Context Engine

> Inject the right context into every AI conversation.

A Chrome extension that lets you create context presets — your goals, projects, working style, and AI persona — and inject them instantly into Claude, ChatGPT, Gemini, and more.

## Features
- 🚀 8 ready-made templates (Solo Founder, Full Stack Dev, Content Creator...)
- ✨ AI Prompt Architect — Groq rewrites your context into an optimized system prompt
- ⚡ 3-layer Coding Agent architecture for developers
- 🎯 Smart preset suggestions based on the site you're on
- 📄 PRD document upload for Founder presets
- 📝 Import any saved prompt as a preset
- 🔒 100% local — no account, no tracking, no servers

## Install
Coming soon to Chrome Web Store.

Manual install:
1. Download the latest zip from Releases
2. Go to `chrome://extensions`
3. Enable Developer Mode
4. Click "Load unpacked" → select the `dist` folder

## Built with
Svelte · TypeScript · Groq API · chrome.storage.local
